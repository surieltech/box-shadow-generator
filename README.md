# 🎨 Gerador de Box Shadow

Ferramenta interativa para criar sombras CSS com preview em tempo real.

## ✨ Funcionalidades

- Preview em tempo real
- Sliders para todos os parâmetros
- Seletor de cores com conversão HEX → RGBA
- Controle de opacidade
- Opção inset (sombra interna)
- Geração automática de CSS com prefixos

## 🚀 Tecnologias

- JavaScript (POO)
- CSS3 (Flexbox + Responsivo)
- HTML5

## 🎯 Como usar

1. Ajuste os sliders
2. Escolha a cor
3. Veja o preview
4. Copie o código CSS

## 📱 Responsivo

Funciona em desktop, tablet e celular.
